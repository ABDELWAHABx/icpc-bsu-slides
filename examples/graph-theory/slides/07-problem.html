A

Shortest Route

Easy-Medium graphs
time 2 smemory 256 MB

You are given a weighted directed graph with n vertices and m edges. Find the length of the shortest path from vertex 1 to vertex n. If no path exists, print -1.

Input

First line: n m (2 ≤ n ≤ 10⁵, 1 ≤ m ≤ 2·10⁵).
Next m lines: u v w (1 ≤ w ≤ 10⁹).

Output

A single integer — the shortest distance, or -1.

INPUT#1
4 5
1 2 1
1 3 4
2 3 2
2 4 6
3 4 3
OUTPUT#1
6
HINT
Path 1→2→3→4 costs 1 + 2 + 3 = 6. Watch the weight range…
