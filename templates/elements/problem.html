Shortest Route

Easy-Medium
time 2 smemory 256 MB

You are given a weighted directed graph with n vertices and m edges. Find the shortest path from vertex 1 to vertex n, or print -1.

Input

First line: n m (2 ≤ n ≤ 10⁵). Next m lines: u v w (1 ≤ w ≤ 10⁹).

Output

A single integer — the shortest distance, or -1.
